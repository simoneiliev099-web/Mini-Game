# Mini-Game
Guess The Number

This is a simple C# console game where you have to guess a random number.

What the game has
Main menu
3 difficulty levels
Random number
Tells you if your guess is too high or too low
Counts your attempts
High score
Play again option
Difficulty
Easy: 1-50
Medium: 1-100
Hard: 1-500
How to play

First you choose if you want to start the game or exit.

If you start the game, you choose a difficulty.

The game then chooses a random number and you have to guess it.

After every guess the game tells you if the number is too high or too low.

The goal is to guess the number with as few attempts as possible.

How to run

You need to have .NET installed.

Run the project with:

dotnet run
